# hakka-ui

Shared Vue 3 UI library for FunNow Group (FunNow, Eatigo, Niceday), built on [Naive UI](https://www.naiveui.com/).

[Storybook 👀](https://myfunnow.github.io/hakka-ui/)

## Usage

> Not published to the npm registry yet.

### Install

`vue` and `naive-ui` are peer dependencies, so install them in your app:

```bash
pnpm add vue naive-ui
```

For local development, run `pnpm install` in hakka-ui first (it builds `dist/` automatically), then install it from the local path:

```bash
pnpm add file:../hakka-ui
```

### Import

```ts
import { createApp } from 'vue'

import { plugin } from 'hakka-ui'
import 'hakka-ui/style.css'

import App from './App.vue'

createApp(App).use(plugin).mount('#app')
```

`plugin` registers every component globally. To use a single component:

```ts
import { components } from 'hakka-ui'

const { ZdPagination } = components
```

### Fonts

hakka-ui does not bundle fonts. Load each brand's fonts in your app through the Google Fonts CDN.

## Development

### Requirements

- Node.js >= 22
- pnpm >= 10

### Scripts

| Script              | Description                                     |
| ------------------- | ----------------------------------------------- |
| `pnpm install`      | Install dependencies and build via `prepare`    |
| `pnpm dev`          | Start the playground in `dev/`                  |
| `pnpm storybook`    | Start Storybook                                 |
| `pnpm build`        | Build the library (JS, CSS, types) into `dist/` |
| `pnpm test`         | Run Vitest                                      |
| `pnpm typecheck`    | Type check                                      |
| `pnpm lint`         | Run ESLint with auto fix                        |
| `pnpm format:check` | Check formatting with oxfmt                     |
| `pnpm format:fix`   | Format with oxfmt                               |

### VS Code

Install the recommended extensions in `.vscode/extensions.json`. `.vscode/settings.json` formats with oxfmt on save, then applies ESLint fixes.

### Create a component

Use the [Blueprint](https://marketplace.visualstudio.com/items?itemName=teamchilla.blueprint) extension to generate a component from `blueprint-templates/`:

1. Right click the `src/components` folder and select `New File from Template`
2. Select `New Component`
3. Enter the component name and press `Enter`

### Styles

Components use [UnoCSS](https://unocss.dev/) utility classes. The build runs UnoCSS in `vue-scoped` mode, which compiles the utilities each component uses into its scoped style. Apps do not need UnoCSS installed.

### Design tokens

`src/tokens/{brand}/` is generated by the token-transformer in [funnow-group-figma](https://github.com/myfunnow/funnow-group-figma) and synced here by an automated PR. **Do not edit it by hand.** Change the tokens in Figma instead.
